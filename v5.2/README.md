# QRREC V5.2：全屏光码发送端

V5.2 是基于 V5.1 的显示面积实验版。编码协议、20 FPS 默认发送参数及 iOS 原生 C++ 解码链路保持不变，只扩大网页端彩色矩阵的显示面积，用于对比定位成功率、有效解码 FPS 和接收速率。

当前真机结果：普通 **B 模式**可以正常接收，App 显示速率达到 **180 KB/s**；**Bm 矩形模式**未能正常接收，暂不推荐使用。

- 在线发送端：`https://qrrec.liuwa.xyz/v5.2/send/`
- 接收端：继续使用 QRREC V5.1 原生 iOS App。
- 点击“开始传输”后会请求浏览器全屏，隐藏其他界面并让光码填满可用视口。
- 全屏时保留右上角“结束传输”按钮；退出系统全屏也会结束本轮传输。
- 浏览器拒绝全屏权限时，仍会使用整个网页视口显示光码。

本地预览：

```bash
npm run dev:sender:v52
```

生产构建：

```bash
npm run build:sender:v52
```

构建产物位于 `release/web-receiver/v5.2/send/`。
